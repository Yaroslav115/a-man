# A-Man Documentation

Documentation is divided into two areas:

- `ARCHITECTURE.md` — canonical architecture for the complete system.
- `standard/` — project documentation intended for users and contributors.
- `internal/` — operational records for the team and agents working on the project.

Project-wide test usage and structure are documented in `../tests/README.md`.

Do not place secrets, passwords, private keys, or access tokens in either area.
