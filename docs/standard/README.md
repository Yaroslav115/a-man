# A-Man

## Overview

A-Man is a system for working with agents through three primary elements:

1. A user interface supporting text, speech, and future input/output modes.
2. An agent that processes a request and produces a result.
3. A controller that connects the UI to one selected agent.

All communication between the UI and an agent passes through the controller.
